MINI SHOOTER 3D — Android + do'stlar bilan o'ynash

Bu papkada o'yin ham, server ham bor (server.js). Server do'stlarni bir-biriga ulaydi
va o'yin sahifasini ham beradi.

1) SERVERNI INTERNETGA QO'YING (bir marta)
   Render.com (bepul tarif bor):
   - Fayllarni GitHub'ga yuklang (yangi repository).
   - render.com -> New -> Web Service -> o'sha repository'ni tanlang.
   - Build Command: bo'sh qoldiring. Start Command: node server.js
   - Deploy tugagach, sizga https://nomingiz.onrender.com ko'rinishida havola beriladi.
   Eslatma: bepul tarifda server 15 daqiqa jim tursa uxlaydi, birinchi ochilishi ~1 daqiqa oladi.

   Kompyuteringizda sinash uchun: node server.js  ->  http://localhost:3000

2) ANDROID'GA ILOVA QILIB O'RNATING
   a) Eng oson (APK kerak emas): havolani Chrome'da oching -> menyu (⋮) -> "Ilovani o'rnatish"
      (Install app) yoki "Bosh ekranga qo'shish". Ikonka paydo bo'ladi, o'yin to'liq ekran
      va yotiq holatda ochiladi.
   b) APK fayl kerak bo'lsa: pwabuilder.com ga havolangizni kiriting -> Android -> Download.

3) DO'STLAR BILAN O'YNASH
   Hamma o'sha havolani ochadi -> lobida bir xil xona kodini yozadi -> "XONAGA ULANISH".
   Birinchi kirgan "BOSHLASH"ni bosadi. O'rmon (botlarga qarshi) yoki Jang maydoni (1v1 / 2v2).
